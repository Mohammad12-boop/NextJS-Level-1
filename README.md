## Getting Started

Install dependencies using npm:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.

## Production commands

Create a production build:

```bash
npm run build
```

Start the production server after the build succeeds:

```bash
npm start
```

Stop either server with `Ctrl+C`. In Windows PowerShell, if script execution policy blocks `npm`, use `npm.cmd` for these commands (for example, `npm.cmd run dev`).
